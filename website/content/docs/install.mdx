<Callout type="warn" title="Always pin the version">
  `3.0.0a2` is an alpha preview. A bare `pip install agentbreeder`, `uvx agentbreeder` or
  `pipx run agentbreeder` installs **2.7.3**, which is unmaintained and has known functional and
  security issues (see [Legacy 2.x](/docs/legacy-2x)). 3.x is a rebuild: no 2.x command, config or
  data carries over.
</Callout>

## Requirements

- macOS (verified end to end) or Linux (install, `--version` and `doctor` only, on `3.0.0a1`; see
  [what has been verified](#what-has-been-verified)). Windows is not supported.
- A running Docker engine with a local context.
- For pip: Python 3.11 or newer.
- For uvx: [uv](https://docs.astral.sh/uv/) 0.11.6 or newer.
- For npx: Node.js 18 or newer, and uv 0.11.6 or newer.

## Install and run the demo

Pick one path. Each runs the same PyPI release.

```sh title="pip, in a virtual environment"
python3 -m venv .venv
.venv/bin/python -m pip install "agentbreeder[eval]==3.0.0a2"
.venv/bin/agentbreeder quickstart
```

```sh title="uvx"
uvx --from "agentbreeder[eval]==3.0.0a2" agentbreeder quickstart
```

```sh title="npx"
npx agentbreeder@3.0.0-alpha.2 quickstart
```

The npm package is a launcher with no Python code of its own. It runs the pinned PyPI release
through `uvx`, and exits with install guidance if `uvx` is missing.

`quickstart` builds a sample image, deploys it through a demo identity gate, invokes it, retries
the same deployment, checks the saved history and removes the container. It needs no model account
or API key. The sample echoes JSON; it is not an AI agent. Add `--dry-run` to run `doctor` and
validate the sample without building or deploying anything. If it stops, run
`agentbreeder doctor` first.

## Run more commands

`npx` and `uvx` run the CLI without installing an `agentbreeder` command. After either, a bare
`agentbreeder` is either not found or an older install. Repeat the prefix for every command
(`npx agentbreeder@3.0.0-alpha.2 up`), or install the command with uv:

```sh
uv tool install "agentbreeder[eval]==3.0.0a2"
agentbreeder --version   # 3.0.0a2
```

This puts `agentbreeder` in uv's executable directory (`~/.local/bin` in our run), which must be on
your `PATH` ahead of any older install. `uv tool uninstall agentbreeder` removes it. Run on macOS on
2026-11-11 in a clean sandbox: `--version`, `doctor` and a real `quickstart` (5/5); `up` and
Northwind have not been run this way.

### An older `agentbreeder` on your `PATH`

If a bare `agentbreeder` fails with `ModuleNotFoundError: No module named 'cli'`, or does not report
`3.0.0a2`, an older install comes first on your `PATH`:

1. `which -a agentbreeder` lists every copy, in `PATH` order.
2. Run each one by its full path with `--version`. The one that fails or reports another version is
   the old one; leave the `3.0.0a2` copy alone.
3. Remove the old one with the tool that installed it: `pipx uninstall agentbreeder`,
   `brew uninstall agentbreeder`, or for a pip install `PYTHON -m pip uninstall agentbreeder`, where
   `PYTHON` is the interpreter on the first line of that script. If pip says it is not installed
   (a leftover from a deleted editable install), delete that script file.
4. Run `hash -r` or open a new shell.

## Try Northwind

Northwind is a customer support agent built from an `agent.yaml`. It needs `GEMINI_API_KEY` and
`TAVILY_API_KEY`, in the environment or in an env file. These commands need `agentbreeder` on your
`PATH`: after the pip install above, run `export PATH=$PWD/.venv/bin:$PATH` first, or use
`uv tool install` ([Run more commands](#run-more-commands)).

```sh
agentbreeder example northwind   # copies it to ./northwind
cd northwind
agentbreeder services up --environment dev --env-file ~/.env --yes
agentbreeder release agent.yaml --stack . --environment dev
```

With uvx or npx, replace `agentbreeder` with `uvx --from "agentbreeder[eval]==3.0.0a2" agentbreeder`
or `npx agentbreeder@3.0.0-alpha.2`. On `3.0.0a1` these CLI commands ran from the pip install. On
`3.0.0a2` they have not been run; Northwind ran through the command center instead, started with
npx and driven by a script through its API, with no browser.

To use the command center, run `npx agentbreeder@3.0.0-alpha.2 up` and follow the steps in the
browser; see [Local command center](/docs/command-center).

To tear it down, run `agentbreeder remove ID --local --stack .`, then
`agentbreeder services down --purge --yes`. See [Backing services](/docs/services) and
[Build from agent.yaml](/docs/agent-yaml).

## How long it took

Measured once each on macOS, each path in its own clean sandbox (the `3.0.0a1` rows on
2026-11-10). Docker images and build layers already on the machine were not cleared, so a first run
on a new machine will take longer.

| Step | Time |
|---|---|
| Create a virtual environment and `pip install` (`3.0.0a1`) | 9 s |
| `agentbreeder quickstart`, cold sample build (`3.0.0a1`) | 62 s |
| `quickstart` including the install, Docker image cache not cleared (`3.0.0a2`: pip, uvx, npx) | 22 s, 9 s, 11 s |
| Command center: start services (5 services, `3.0.0a2`) | 162 s |
| Command center: release (build, 61 evals, promote, `3.0.0a2`) | 189 s |

Not measured: installing Docker, Python, uv or Node, or getting the API keys.

## Install with hashes

The [`v3.0.0a2` GitHub release](https://github.com/agentbreeder/agentbreeder/releases/tag/v3.0.0a2)
carries `requirements-3.0.0a2.txt`, with a hash for every package, and a `SHA256SUMS` file.

```sh
uv pip install --require-hashes -r requirements-3.0.0a2.txt
# or
pip install --require-hashes -r requirements-3.0.0a2.txt
```

Neither uvx nor npx enforces hashes. The npx launcher bounds what resolves with `--exclude-newer`
and a constraints file. The uvx command above pins only `agentbreeder` itself, so its dependencies
resolve to the newest versions allowed. On both paths, your uv index settings decide where the
packages come from.

## Install from a checkout

Use a fresh virtual environment: an older install can expose the 2.x CLI.

```sh
git clone https://github.com/agentbreeder/agentbreeder.git
cd agentbreeder
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
```

## Using 2.x

If you need 2.x, pin `agentbreeder<3` and read [Legacy 2.x](/docs/legacy-2x) first. There is no
migration path between 2.x and 3.x.
