Build agents entirely in code with the AgentBreeder SDK. Full type safety, custom routing logic, and state machines. The SDK generates `agent.yaml`; you deploy it with `agentbreeder deploy`.

**Who this is for:** Senior engineers, AI researchers, ML scientists, and teams building production systems that need custom routing logic or CI/CD-driven deploys.

## Supported Frameworks

The SDK supports all 6 frameworks. Pass the framework name as a string — AgentBreeder resolves the right runtime.

| Value | Framework |
|-------|-----------|
| `"langgraph"` | LangGraph (LangChain) |
| `"openai_agents"` | OpenAI Agents SDK |
| `"claude_sdk"` | Anthropic Claude SDK |
| `"crewai"` | CrewAI |
| `"google_adk"` | Google Agent Development Kit |
| `"custom"` | Bring your own entrypoint |

---

## Supported Deployment Targets

All 7 deployment targets available via `.with_deploy()`:

| `cloud` | Default `runtime` | Also supports |
|---------|------------------|---------------|
| `"local"` | `"docker-compose"` | — |
| `"aws"` | `"ecs-fargate"` | `"app-runner"` |
| `"gcp"` | `"cloud-run"` | — |
| `"azure"` | `"container-apps"` | — |
| `"kubernetes"` | `"deployment"` | — |
| `"claude-managed"` | *(no container)* | — |

## Python SDK

### Install and full-featured deploy

```python
from agenthub import Agent, Tool

agent = (
    Agent(
        "support-agent",
        version="1.0.0",
        description="Handles tier-1 customer support",
        team="customer-success",
        owner="alice@company.com",
        framework="langgraph",
    )
        .tag("support", "zendesk", "production")
        .with_model(
            primary="claude-sonnet-4",
            fallback="gpt-4o",
            temperature=0.7,
        )
        .with_tool(Tool.from_ref("tools/zendesk-mcp"))
        .with_tool(Tool.from_ref("tools/order-lookup"))
        .with_prompt(system="prompts/support-system-v3")
        .with_guardrail("pii_detection")
        .with_guardrail("hallucination_check")
        .with_guardrail("content_filter")
        .with_deploy(
            cloud="aws",
            runtime="app-runner",
            region="us-east-1",
            scaling={"min": 1, "max": 10, "target_cpu": 70},
            secrets=["ZENDESK_API_KEY", "OPENAI_API_KEY"],
        )
)

agent.save("agent.yaml")
```

The SDK has no builder for the `access:` block — add `visibility` / `allowed_callers` to the saved `agent.yaml` if you need them.

Then deploy the generated file with the CLI:

```bash
agentbreeder deploy agent.yaml --target aws
```

### Deploy to Claude Managed Agents

```python
from agenthub import Agent

agent = (
    Agent("managed-support", framework="claude_sdk")
        .with_model(primary="claude-sonnet-4")
        .with_deploy(
            cloud="claude-managed",
            secrets=["ANTHROPIC_API_KEY"],
        )
)

agent.save("agent.yaml")
# The SDK has no builder for the `claude_managed:` block — add
# environment / tools settings to the saved agent.yaml by hand.
```

```bash
agentbreeder deploy agent.yaml --target claude-managed
```

### Generate and validate agent.yaml

```python
agent.save("agent.yaml")          # write agent.yaml for YAML-based workflows
yaml_text = agent.to_yaml()        # or get the YAML as a string
errors = agent.validate()          # validate without deploying; [] means valid
```

## TypeScript SDK

```typescript
import { Agent, Tool } from "@agentbreeder/sdk";

const agent = new Agent("support-agent", {
  version: "1.0.0",
  description: "Handles tier-1 customer support",
  team: "customer-success",
  owner: "alice@company.com",
  framework: "langgraph",
  tags: ["support", "zendesk", "production"],
})
  .withModel("claude-sonnet-4", {
    fallback: "gpt-4o",
    temperature: 0.7,
  })
  .withTool(Tool.fromRef("tools/zendesk-mcp"))
  .withTool(Tool.fromRef("tools/order-lookup"))
  .withPrompt("prompts/support-system-v3")
  .withGuardrail("pii_detection")
  .withGuardrail("hallucination_check")
  .withDeploy("aws", {
    runtime: "app-runner",
    region: "us-east-1",
    secrets: ["ZENDESK_API_KEY"],
  });

await agent.save("agent.yaml");
```

Then deploy it with `agentbreeder deploy agent.yaml`. To get the YAML as a string instead:

```typescript
const yaml = agent.toYaml();
```

## Agent-to-Agent (A2A) Calls

Register agents in the A2A registry, then call them by name through the AgentBreeder API:

```bash
curl -X POST "https://your-agentbreeder/api/v1/a2a/invoke?agent_name=specialist-agent" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"input_message": "Customer is asking about order #12345"}'
```

From Python, `engine.a2a.AgentInvocationClient` makes the same call. See the [A2A guide](a2a-protocol) for the registry API and the sidecar forwarder.

Restrict which agents can call yours via `access.allowed_callers` in agent.yaml:

```yaml
access:
  allowed_callers:
    - team:engineering
    - agent:triage-agent
```

## CI/CD Integration

Generate `agent.yaml` from code (or commit it directly), then deploy it with the CLI in GitHub Actions / GitLab CI:

```bash
agentbreeder validate agent.yaml
agentbreeder deploy agent.yaml --target aws --json
```
