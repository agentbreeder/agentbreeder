# Account and security

Password reset: choose "Forgot password" on the sign-in page. The reset link is valid for 60 minutes. If no email arrives, check spam and confirm the address is the one on the account.

Two-factor authentication (2FA) can be enabled under Settings > Security using an authenticator app or a hardware security key. Customers who lose their 2FA device can use one of the ten backup codes issued at setup. Without backup codes, identity must be verified by the security team; support agents must never disable 2FA themselves.

Account deletion is permanent after a 14-day grace period. During the grace period the owner can restore the account from the deletion email.

Team plan SSO supports SAML 2.0 and OIDC (Okta, Microsoft Entra ID, Google Workspace).
