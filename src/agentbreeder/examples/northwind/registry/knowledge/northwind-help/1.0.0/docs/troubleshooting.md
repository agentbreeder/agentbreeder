# Troubleshooting sync and the apps

Sync stuck: confirm the app version is 4.2 or later (Settings > About), sign out and back in, then check status.northwindnotes.example for incidents. Notes edited offline sync automatically when the device reconnects; conflicting edits are kept as "conflicted copy" notes.

Desktop apps run on macOS 13+, Windows 10+ and Ubuntu 22.04+. Mobile apps need iOS 17+ or Android 12+.

Attachments are limited to 250 MB per file on Pro and Team, 25 MB on Free.

Export: File > Export supports Markdown, PDF and HTML. Whole-workspace exports are available to owners under Settings > Data > Export workspace and arrive by email as a ZIP within 24 hours.

Importing from other note apps: Northwind imports Evernote ENEX files, Markdown folders and Notion HTML exports via File > Import.
