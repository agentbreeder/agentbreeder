- `agentbreeder tool log tool/NAME[@X.Y.Z]` lists a registry tool's recorded calls from the stack's database, read-only: agent, version, function, status, latency, turn and trace id, and the inserting database role, with arguments and error text only under `--content` (redacted). It reads with the agent's own credential where the agent owns the tables and as `agentbreeder_console` where the database owner made them, refusing tables that carry unexpected triggers, row security or rules. The duplicate `ok` rows that `runtime/adk` 1.0.6/1.1.0 wrote after a failed call (#922) are left out and counted. See [`docs/commands/tool.md`](docs/commands/tool.md). On `main`, not in a published preview.
