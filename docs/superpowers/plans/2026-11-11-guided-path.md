# Plan: guided path and command center for 3.0.0a3 (#807)

Spec: `docs/superpowers/specs/2026-11-11-guided-path-design.md` (r3; §9 and §14 binding).
Issues: #807 (epic), #805, #769, #809, #810, #811. One preview, 3.0.0a3, built in two steps; each
task lands as its own PR behind the gate and a different-model review, in this order. Step 1 must
stay releasable on its own in case step 2 slips.

Conventions for every task: tests first; `--json` output before UI; no secret value printed or
stored; text from models, logs or repositories is stripped of control characters and capped; the
center runs only fixed argv and places text with `textContent`.

## Release 3.0.0a3

1. Prep PR: version, CHANGELOG, pins (as #803). 2. Tag, release.yml, owner approves TestPyPI/PyPI, owner publishes npm. 3. Verify from the registries in a clean sandbox on macOS: the whole step 1 path via `npx` following only `Next:` lines; the center via API and a browser click-through (Agents, Registry, Logs with follow during a release, notifications: zero events on a clean release, one on a killed service); key leak scan; teardown to zero. Linux: install, `next`, `new agent`, `services up`, `release` in a container with a Docker socket if available, else "Not run". 4. Docs PR updating claims only for what ran (as #804).
