## Findings

1. **#978 is still present on f0606ef.** It did not fail here, but both container starts the
   loop sampled (step 14's candidate and production) showed `"8080/tcp": []` for one 0.3 s sample (see "The deploy race" above). Re-run a
   release after the #978 fix lands.
2. **No video on macOS 13.** Playwright 1.64.1 cannot record video on macOS 13 (no ffmpeg build).
   A console video for a milestone record needs macOS 14 or later, or Linux.
3. A console one-time link works once. A second Playwright run needs a new `up`, or a new link
   (Enter in the `up` terminal). That is intended behaviour, not a finding: run 2 failed because I
   reused the link.
