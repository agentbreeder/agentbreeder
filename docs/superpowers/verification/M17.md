# M17 verification: Agent builder (#833)

Status: **partial: the acceptance is NOT met from the form** (2b4e4cf, after #1008, 2026-11-15,
macOS 13.7.8 x86_64, Docker Desktop engine 27.5.1). The acceptance is "an agent with gemini, a
prompt, evals and one verified tool is created from the form and released".
- **From the form, not met.** The console's Build an agent form previews a spec with a tool but
  will not create it: Create stays off with "This combination has not been run end to end".
  That is by design: `agentspec.VERIFIED` holds only model + prompt + evals, with or without one
  knowledge version, and the console refuses knowledge on its own.
- **From the form, without the tool: created and released.** A gemini + prompt + evals agent
  (`kettle-helper`) was created from the form and released from the console's **Run release**
  (1/1). It answered in Try it.
- **The same parts with a tool, created by `new agent --from-spec`: released.** A gemini +
  prompt + evals + one tool + one knowledge version spec (`kettle-desk`) was written by the CLI
  (which writes unverified combinations). It released 2/2. It called its tool and answered from
  its knowledge, in two separate sandboxes. This is evidence toward adding a tool combination to
  `VERIFIED`, which is a separate follow-up like #1008 and not done here.
- **Knowledge (after #1008):** worked through `--from-spec`. `knowledge status` was fresh (3 of 3
  chunks), and the agent quoted a help article. It ran combined with a tool, not on its own.

#833 stays open. The leak scan found 0 hits in both sandboxes, and Docker was torn down to the
pre-run snapshot. The console run was recorded as a video for the owner (not committed, not
attached).

This is on `main`, not in a published preview.

## What the form allows

Create is on only when the CLI's dry run says `combination.verified`. The console adds its own
refusal of knowledge (`center/builder.py`; the form says "Knowledge is not on this form yet").
On 2b4e4cf, that leaves exactly one combination:

| Spec | Preview | Create |
|---|---|---|
| gemini + prompt + evals | "Run end to end: model, prompt, evals." | **on** |
| gemini + prompt + evals + a tool | "Not run end to end yet: a new agent with tools. The console creates only combinations that have been; `agentbreeder new agent --from-spec` writes it anyway." | off |
| … + an MCP server | "… with MCP servers" (per `docs/command-center.md`; not tried in this run) | off |
| … + knowledge | not offered on the form; the server refuses a spec with knowledge (`SPEC_UNSUPPORTED`) | n/a |
| anthropic, openai or openrouter (any parts) | the provider is marked "(not run end to end)" | off |

Playwright replaces the Chrome GIF (owner process change, 2026-11-13). The run was recorded as
one 5 min 7 s video at 1440x900 in the light theme. It is kept outside the repo for the owner,
not committed and not attached to an issue. Before it was handed over, all 618 frames (2 per
second) were read with macOS Vision OCR and searched for the OS user name, home paths, emails
and key fragments (the first and last 8 characters of each `~/.env` value). The only hits were
false positives: "https" read as "os:", the demo `example.com` sponsors, and "sk-" inside
`kettle-desk-`. The four stills were also checked by eye.
