## Leak scan and teardown

**Leak scan.** Before teardown, while the stacks' secrets still existed, a stdlib script searched
95 files:
- every saved output, including the console's `up` output and the Playwright logs;
- the three projects' eval reports and build records under `deploy/`;
- the console's state directory and the three stacks' saved release files;
- the three production containers' logs.

It looked for the literal, base64 and URL-quoted forms of:
- every `~/.env` value of 12 or more characters (6 values);
- every stored secret of 12 or more characters under the sandbox's `~/.agentbreeder` (47 files
  under its `secrets` paths).

It also looked for `/Users/`. Result: **0 hits**. The counts were printed to a saved file.

**Teardown (02:28:09–02:28:44):**
1. The console was stopped.
2. `remove … --local` for the three production deployments (exit 0 each; 2.6 s, 1.4 s, 1.3 s).
3. `services down <dir> --purge --yes` for the three stacks (exit 0 each; 12.5 s, 10.4 s, 7.2 s):
   their containers, volumes, Northwind's two built service images (ops, proxy) and the stack
   state.
4. The three agent images this run built (`be12aa25…`, `8eb3704a…`, `af38c840…`) were removed with
   `docker rmi`. Nothing was pruned.
5. The key file was deleted.

After teardown, no container, volume, image or network of this run was left, and images matched
the snapshot taken before the run exactly. The container, volume and network lists differed only
by other sessions' stacks: `demo-959ea835` (present before, gone after) and `demo-d3c59ace`
(created during the run). Neither is this run's, and both were left alone.

## Findings

1. **#978 is still present on f0606ef.** It did not fail here, but 3 of 6 container starts showed
   `"8080/tcp": []` on their first `running` sample. Re-run a release after the #978 fix lands.
2. **Northwind's Last release cell can lag.** With three projects, the Agents list showed "…" for
   Northwind's last release 5 s after the table appeared (it fills in as each project's audit is
   read, one after another, as `docs/command-center.md` says). Not a failure; worth watching as the
   number of projects grows.
3. `services up` printed `WARNING: gateway config serves aliases the environment doesn't grant:
   ['support-model-openrouter']` for Northwind. It names an alias in Northwind's gateway config
   that the environment does not grant. It did not affect the run; its cause was not looked into.
