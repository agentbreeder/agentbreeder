## Findings

1. **`release` prints no `Next:` line.** After a successful release, the user must run `next`
   again (printed earlier by `new agent`) to be shown `Done. Try it: agentbreeder invoke …`. The
   guided spec does not require a line here, so this is not an acceptance failure; a small
   follow-up is to end a successful `release` with `Next: … invoke NAME Hello --stack … --environment
   …`.
2. **`next` exits 1 while steps remain** (step 3), by design (`docs/commands.md`). A script that
   follows `Next:` lines must not stop on it.
