# Focused rebuild reference

Use a fresh virtual environment. Install `python -m pip install -e ".[dev]"`. Run `agentbreeder --help`, `agentbreeder validate examples/http-agent/agent.yaml`, `agentbreeder doctor`, `python -m pytest`, `ruff check src tests examples/http-agent`, and `python -m build`. Implemented commands: `validate`, `doctor`, `deploy MANIFEST --local --environment ENV` (needs an operator config; see `identity-gate.md` and `first-deployment.md`), `status ID`, `remove ID --local`, `approve`/`reject`, `approve-call`/`reject-call`, `disable`/`enable`, `reconcile --local`, `audit list`/`audit verify`, `login`, `secret set NAME [--from-env VAR [--env-file FILE] | --generate [--force]]` (local secret files, see `local-deployment.md`), `registry new|publish|list|verify` (see `registry.md`), `validate` of agent files, and `build`, `eval` and `release` (see `agent-yaml.md`). Local-only preview, in progress (#734): `services up|status|logs|env|down` start a project's `stack.yaml` backing services with Docker Compose and write a demo operator config under `~/.agentbreeder/stacks/`; `--stack DIR` on `build`, `deploy`, `eval`, `release`, `status`, `remove` and `reconcile` uses it. `doctor` also reports whether Compose v2 supports `up --wait` (a warning, not a failure). Only the built-in `service/echo` test service has run end to end so far. Run `agentbreeder COMMAND --help` for flags; see the root README for the demo.
